# Automated blocking walkthrough

[Watch or download the captioned MP4](media/automated-blocking-walkthrough.mp4).

The recording shows real Datadog UI navigation through:

1. The scoped Agent rule expression and process-termination action.
2. A generated security signal and its automatic-remediation message.
3. The triggering Agent event.
4. The JSON action report with SIGKILL, process scope, status performed, and ttr.

The demonstrated environment used US1. Customers installing this repository
should use the EU1 URLs and settings in the main guide.

Account names, account imagery, infrastructure identifiers, and long container
identifiers have been redacted from the public copy. Redaction changes the
presentation only; it does not alter the response status or remediation timing.
The public recording has no audio track and its original metadata is removed.

No credentials are required to watch the recording. The source recording,
browser profile, authentication state, raw environment exports, and deployment
backups are not included in this repository.
