# Credentials and generated data

The helpers prompt for credentials or read DD_API_KEY and DD_APP_KEY from the
local environment. API keys and application keys must belong to the customer's
own EU1 organization. Do not commit them or include them in issue reports.

The generated/ directory is local deployment state and is excluded from Git.
Keep browser profiles, environment files, Kubernetes Secrets, raw recordings,
and deployment backups outside this repository.

Only the redacted MP4 and its redacted preview are intended for publication.
The original browser recording is not distributed.
